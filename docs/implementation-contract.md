# Desktop Computer Use v1 implementation contract

Transport: one UTF-8 NDJSON request and response per local connection, maximum 16 MiB. Windows named pipe; Linux Unix socket. CLI invokes native executable with `--serve --endpoint PATH --token-file PATH`; session owner credentials stay in a user-only runtime directory. No Orca dependency.

Request `{ "id": "uuid", "token": "local-secret", "method": "get-app-state", "params": {} }`; response `{ "id": "uuid", "ok": true, "result": {} }` or `{ "id": "uuid", "ok": false, "error": {"code":"...", "message":"..."} }`. All method names are CLI kebab-case; sessions use `session.start`, `session.status`, `session.stop`. `daemon.shutdown` terminates the daemon. Native `--version` and `--help` need no desktop.

Native platform interface: `native/include/dcu/backend.hpp`. CMake platform directories supply target `dcu_platform` implementing `make_backend()`. Root builds `desktop-computer-use-native`. Backend handles `doctor`, `capabilities`, `session.start`, `session.stop`, `list-apps`, `list-windows`, `get-app-state`, and actions. Common daemon handles authorization, session leases, session IDs, serialized operations and cancellation. `session.start` must prove indicator ready before succeeding; `interrupt()` must not block behind capture/UIA/input. Actions check Context during waits and release held input with RAII. Sessions end after 120 seconds idle.

Params camelCase: `app`, `windowId` (opaque string), `observationId`, `elementIndex`, `fromElementIndex`, `toElementIndex`, `x`, `y`, `fromX`, `fromY`, `toX`, `toY`, `button` (left/right/middle), `durationMs` (240), `steps` (12), `holdBeforeMs` (50), `holdAfterMs` (50), `direction`, `amount` (3), `text`, `key`, `value`, `includeText` (false), `includeScreenshot` (true), `format` (jpeg), `quality` (85), `maxEdge` (0 = no cap; caps only the reduced screenshot), `observe` (none/screenshot/text/both). CLI converts kebab-case options. Input methods require sessionId in params. Input x/y are pixels of the reduced screenshot by default, or of the full screenshot with `coords: "full"`; the daemon converts them to window-local coordinates with the transform stored for `observationId` or the window's latest screenshot observation, and fails with `observation_required` when none exists. Reject changed window geometry against supplied observationId.

Observation result: `{observationId,capturedAt,window:{id,app,title,x,y,width,height},coordinateSpace:"window",screenshot?:{path,mimeType,width,height,variant:"reduced",actionTransform:{scaleX,scaleY,offsetX,offsetY},fullAvailable,fullWidth,fullHeight},accessibility?:{tree,elements:[{index,...}]},timings?:{},overlayRegions?:[]}`. Native writes the reduced and full image of one frame to a user-private directory, returns the reduced path, serves the full one through `get-full-screenshot`, and deletes both when the observation leaves the cache. MCP reads images into image content; CLI outputs JSON. Actions return `{delivered:true,verification:{state:"unverified"}}`; optional observe attaches `observation`.

Common daemon attaches sessionId and rejects wrong owners. Backend `session.start` returns indicator info and readiness, handles platform permission setup; portal interaction can report `permission_required`/`setup_required`. Do not falsely report unsupported operations as delivered. Backend `doctor` must work without starting input or showing UI.

GNOME extension owns bus `org.desktopcomputeruse.Shell`, object `/org/desktopcomputeruse/Shell`, interface `org.desktopcomputeruse.Shell`. Methods: `Start(s sessionId)->s JSON`, `Stop()->b`, `Heartbeat()->b`, `ListWindows()->s JSON`, `Activate(s windowId)->b`, `Pointer(d x,d y)->b`, `GetPointer()->s JSON`, `GetOverlayRegions()->s JSON` (screen-logical rectangles), `SuspendStopKey(u milliseconds)->b` (unbinds the stop hotkey for at most 2000 ms; native calls it with 300 before injecting an Escape press and fails the action with `stop_key_conflict` if it does not return true). Signal `Stopped(s reason)`. Window JSON uses id/title/app/pid/x/y/width/height (GNOME logical screen coordinates). Extension indicator is nonreactive; hotkey Esc pressed twice within 1 second (any Shift/Control/Alt/Super combination, auto-repeat ignored) stops and emits signal. Auto-hide if heartbeat missing for 5 seconds. Modern/legacy variants install user-locally. Native provides heartbeat while active.

Skill CLI entry `scripts/dcu.mjs`; resolves binary under `bin/win32-x64/desktop-computer-use-native.exe` or `bin/linux-x64/desktop-computer-use-native`, relative to installed skill root, supports DCU_NATIVE_PATH for development. Native executable and CLI bundles are prepared by build/package scripts, no SDK required for users. Package setup includes GNOME extension archives and runtime dependency instructions.
